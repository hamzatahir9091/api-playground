A small playground built to explore, test, and better understand how APIs and backend concepts actually work.

## 💻 Run It Locally

Never cloned a project before? No problem. Just follow these steps.

### 1. Open VS Code

Open **VS Code** and open the folder where you want to keep your projects.

For example:

```text
Projects/
```

Then open:

**Terminal → New Terminal**

---

### 2. Clone the project

In the VS Code terminal, run:

```bash
git clone https://github.com/hamzatahir9091/api-playground.git
```

This downloads the project from GitHub onto your computer.

---

### 3. Go inside the project

Run:

```bash
cd api-playground
```

You should now be inside the project folder.

---

### 4. Install dependencies

Run:

```bash
npm install
```

This installs everything the project needs to run.

---

### 5. Start the development server

Run:

```bash
npm run dev
```

You should see a local address in the terminal, usually:

```text
http://localhost:3000
```

Open that address in your browser.

That's it. 🎉

## 📌 Project Structure

The main application lives inside the `app/` directory, while static assets are kept in `public/`.

```text
api-playground/
├── app/
├── public/
├── package.json
├── tsconfig.json
└── next.config.ts
```

The project uses the standard Next.js development workflow:

```bash
npm run dev
```

and can be built for production with:

```bash
npm run build
```
